Guia rápido para quem está começando

Se os termos "Skill", "Claude Code" ou "MCP" ainda não fazem muito sentido, este guia resolve isso em poucos minutos — antes de você voltar ao catálogo.

Afinal, o que é uma Skill?

Sem termos técnicos: uma Skill é um manual de instruções que você entrega ao Claude para uma tarefa específica.

👩‍🍳 Imagine o Claude como um cozinheiro talentoso. Ele já sabe cozinhar muita coisa — mas se você entrega a receita exata do prato que quer, com os ingredientes e o passo a passo, ele acerta de primeira, do jeito certo, sempre.

📋 Uma Skill é essa receita. Em vez de você explicar tudo de novo a cada conversa, a Skill já carrega as instruções — e, quando a tarefa pede, também traz ferramentas prontas (como um modelo de documento ou um script). É por isso que a mesma tarefa sai melhor e mais rápida com uma Skill do que sem.

✓ Uma Skill é conhecimento que o Claude passa a ter — não um programa separado que você abre.

✓ Ela só entra em ação quando a tarefa combina com o que ela sabe fazer; o resto do tempo fica fora do caminho.

✓ São gratuitas e abertas — feitas pela Anthropic e pela comunidade, e reunidas aqui neste catálogo.

Veja a diferença na prática

Três pedidos do dia a dia, do jeito que o Claude responde sem uma skill e com a skill certa.

🎤 Você pede: "monte uma apresentação sobre os resultados do trimestre"

Sem skill

O Claude escreve o texto dos slides na conversa. Você ainda precisa abrir o PowerPoint e montar tudo à mão — copiar, formatar, alinhar.

Com a skill de apresentações

Você recebe um arquivo .pptx pronto: slides formatados, com títulos, tópicos e visual consistente. É só abrir e apresentar.

📄 Você pede: "transforme este rascunho em um relatório profissional"

Sem skill

Você recebe um texto corrido na tela. Capa, sumário, numeração de páginas e formatação ficam por sua conta depois.

Com a skill de documentos Word

Sai um arquivo .docx com capa, sumário automático, títulos e páginas numeradas — pronto para enviar ou imprimir.

💻 Você pede: "me ajude a programar usando uma ferramenta que saiu esse ano"

Sem skill

O Claude pode sugerir código baseado em versões antigas que ele viu no treino — e aí o código não funciona, porque a ferramenta mudou.

Com a skill Context7

Antes de responder, o Claude consulta o manual atual da ferramenta. O código sai baseado na versão que você realmente usa.

Repare no padrão: a skill não deixa o Claude "mais inteligente" — ela dá a ele o procedimento certo e as ferramentas certas para uma tarefa, para que o resultado venha pronto em vez de pela metade.

As três formas de usar o Claude

As skills deste catálogo funcionam em superfícies diferentes — vale saber qual é a sua antes de instalar qualquer coisa.

claude.ai navegador

O site e o app do Claude. Não precisa instalar nada no computador. Boa parte das skills oficiais da Anthropic (gerar documentos Word, Excel, PDF) funciona aqui.

Claude Desktop aplicativo

Aplicativo para Windows/Mac. Mesma conversa do claude.ai, mas com acesso a servidores MCP instalados localmente — por exemplo, para ler arquivos do seu computador.

Claude Code terminal

Ferramenta de linha de comando para programar. É onde a maioria das skills deste catálogo roda — elas leem e editam arquivos do seu projeto diretamente.

Glossário: os termos que aparecem nos cards

Skill = Habilidade
Um pacote de instruções (e às vezes scripts) que ensina o Claude a fazer uma tarefa específica bem feita — por exemplo, gerar um .pptx com formatação correta. É o que este catálogo reúne. Atenção ao nome: no aplicativo do Claude em português, as Skills aparecem no menu como "Habilidades".
Subagente
Um "assistente" com personalidade e escopo próprios (ex.: revisor de segurança) que o Claude Code aciona para uma parte da tarefa e depois volta o controle para a conversa principal.
Servidor MCP
Uma ponte entre o Claude e um sistema externo — Figma, um banco de dados, o n8n. Depois de configurado, o Claude passa a "enxergar" aquele sistema durante a conversa.
Plugin
Um pacote que agrupa várias skills, subagentes e comandos prontos, instalado de uma vez só no Claude Code (comando /plugin).
Slash command
Um atalho que você digita no Claude Code começando com / (ex.: /security-review) para disparar um fluxo pronto.
Hook
Uma regra automática que roda em resposta a uma ação do Claude Code — por exemplo, bloquear uma edição que não veio acompanhada de teste (é o que o TDD Guard faz).

Como usar uma skill: passo a passo

Escolha abaixo a forma como você usa o Claude. Em todas, a lógica é a mesma: ligar a skill uma vez e depois pedir com as suas palavras.

💡 Antes de tudo, um aviso que evita confusão: aqui no catálogo usamos a palavra "Skill". No aplicativo do Claude em português, essa mesma coisa aparece no menu como "Habilidades" — é o lugar onde você liga cada uma.

🌐

No navegador (claude.ai) ou no app do celular

O jeito mais simples — não instala nada no computador

  1. Entre no Claude e faça login

    Acesse claude.ai pelo navegador ou abra o aplicativo do Claude no celular e entre com a sua conta.

  2. Ligue a habilidade nas configurações

    Abra as Configurações (ícone de engrenagem). No menu à esquerda, na seção Personalizar, clique em Habilidades — é assim que as Skills aparecem no Claude em português. Ligue a que quiser usar (as de criar documentos costumam já vir prontas).

  3. Peça na conversa, com as suas palavras

    Numa conversa comum, escreva o que você precisa. O Claude reconhece sozinho quando usar a skill — você não precisa digitar nenhum comando especial.

Exemplo Digite: "crie uma planilha de Excel com o meu orçamento do mês, com colunas de categoria, valor e total" — e o Claude devolve o arquivo pronto para baixar.

🖥️

No Claude Desktop (computador)

Para quem instalou o aplicativo no Windows ou no Mac

  1. Instale e abra o Claude Desktop

    Baixe o aplicativo no site do Claude, instale como qualquer programa e faça login.

  2. Ative a habilidade nas configurações

    Abra Configurações → Habilidades (na seção Personalizar do menu) e ligue as que quiser. Skills que conectam o Claude a outros programas ficam ali perto, em Conectores ou Plugins — basta seguir a instrução que aparece no card da skill no catálogo.

  3. Peça na conversa

    Descreva a tarefa normalmente. Se você copiou o "prompt inicial" do catálogo, cole-o para o Claude seguir o procedimento completo.

Exemplo Digite: "transforme as anotações deste arquivo em uma apresentação de slides" — e o Claude gera o arquivo .pptx para você.

⌨️

No Claude Code (terminal)

Para quem programa — é onde roda a maioria das skills do catálogo

  1. Escolha uma skill no catálogo

    Abra o catálogo, use a busca ou os filtros e clique em "Detalhes".

  2. Copie a instalação e rode no terminal

    Use o botão "Copiar instalação" no modal e cole o comando no terminal (em geral algo como /plugin install …).

  3. Copie o prompt inicial e descreva sua tarefa

    Use "Copiar prompt", cole no Claude Code e complete com o que precisa. O prompt já pede para o Claude analisar o projeto antes de mexer em qualquer coisa.

Exemplo Depois de instalar o TDD Guard, peça: "implemente o cálculo de frete seguindo TDD" — e cada mudança nasce acompanhada de um teste.

💡 Em qualquer uma das formas você não precisa decorar comandos: ligue a skill uma vez e depois é só conversar. O botão "Copiar prompt" do catálogo já te dá um pedido bem escrito para começar.

Vamos fazer juntos: um exemplo do começo ao fim

Caso real: você tem anotações bagunçadas de uma reunião e quer um relatório em Word organizado. Veja cada passo — e em qual tela você está.

  1. Aqui no catálogo

    Na barra de busca no topo do catálogo, digite "Word". Aparece a skill "Agent Skills (oficial Anthropic)", que cria documentos.

  2. Aqui no catálogo

    Clique em "Detalhes" para ver como ela funciona. Quer um pedido já prontinho? Clique em "Copiar prompt" — mas, para este exemplo, vamos escrever com as nossas próprias palavras, que é ainda mais simples.

  3. Agora no Claude

    Abra o claude.ai no navegador (ou o app no computador/celular) e faça login. Só na primeira vez: vá em Configurações → Habilidades (seção Personalizar) e confirme que a habilidade de criar documentos está ligada.

  4. Agora no Claude

    Comece uma conversa nova e escreva o seu pedido, colando as anotações no fim. Algo assim:

    Você escreve no Claude

    Transforme estas anotações da reunião de hoje em um relatório em Word, com título, data e os assuntos organizados em tópicos:

    – orçamento do novo site aprovado
    – lançamento previsto para novembro
    – João ficou responsável pelo contrato

  5. Agora no Claude

    Aperte enviar. Em segundos o Claude monta o documento e te entrega um arquivo para baixar:

    📄
    relatorio-reuniao.docx Clique para baixar — o arquivo abre no Word, já formatado.

🔁 A mesma receita serve para tudo: quer uma planilha em vez de um relatório? No passo 1, busque "Excel". Uma apresentação? Busque "PowerPoint". Você troca a skill; o passo a passo é igual.

Perguntas frequentes

Preciso pagar para usar essas skills?

As skills em si são gratuitas e de código aberto — o que você paga é o seu plano do Claude (há um nível gratuito). Algumas skills usam serviços de terceiros (ex.: uma chave de API do Figma) que podem ter custo próprio; isso está descrito na instalação de cada uma.

Preciso saber programar?

Para as skills que rodam em claude.ai ou no Claude Desktop, não. Para as que rodam no Claude Code, ajuda saber usar o terminal, mas a maior parte da instalação é copiar e colar um comando pronto — o catálogo já te dá o comando exato.

Funciona no Windows?

O Claude Code roda em Windows (nativo ou via WSL), macOS e Linux. Skills baseadas em comandos de terminal funcionam nos três; verifique a nota de instalação de cada uma se tiver dúvida.

Qual a diferença entre uma skill e um subagente?

Uma skill ensina o Claude a executar uma tarefa (o "como fazer"). Um subagente é um especialista com escopo próprio que o Claude aciona para cuidar de uma parte do trabalho (o "quem faz"). Muitos pacotes do catálogo trazem os dois juntos.

Posso usar várias skills ao mesmo tempo?

Sim — é o caso mais comum. As trilhas por perfil do catálogo já sugerem combinações testadas, em ordem de instalação.

Pronto para escolher suas skills?

Volte ao catálogo e clique numa trilha por perfil, ou descreva seu projeto no recomendador.
